TASKFLOW PREMIUM — SIAP DIPUBLISH

1. Ekstrak ZIP.
2. Upload SEMUA isi folder TaskFlow-Premium ke repository GitHub baru.
3. Di GitHub buka Settings > Pages.
4. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
5. Setelah link Pages aktif, buka link itu di HP.
6. Android: menu browser > Add to Home screen.
   iPhone: buka dengan Safari > Share > Add to Home Screen.

Jalankan lokal: buka folder di VS Code lalu gunakan Live Server.
Data tugas tersimpan pada browser/perangkat yang digunakan dan tidak otomatis tersinkron antarperangkat.
PWA membutuhkan HTTPS (contohnya GitHub Pages) atau localhost.
